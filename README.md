# Mastermind

A personal thinking instrument for a world built to move you. It combines four lenses:

| Lens | Source | Tool |
|---|---|---|
| **Influence** | Cialdini, *Influence: The Psychology of Persuasion* | **Influence Radar**: paste any message and see which persuasion levers it pulls, with a counter-move for each |
| **Desire** | Girard, *Things Hidden Since the Foundation of the World* | **Desire Audit**: trace a desire back to its model and measure how mimetic it is |
| **Biology** | Sapolsky, *Behave* | **Behavior Decoder**: explain an action across timescales, from one second before to evolution, and find the levers |
| **Reason** | Halpern, *Thought and Knowledge* | **Thinking Gym**: adaptive drills on biases, probability, and argument |

Also included:

- **Decision Lab**: Halpern's weighted decision worksheet, plus a mind check (HALT, scarcity, reciprocity, mimetic pull, sunk cost) and a pre-mortem.
- **Codex**: 40 core ideas, each with a way to use it.
- **Future Field Guide**: seven pressures already building (AI persuasion, synthetic media, algorithmic envy, automation and status, scapegoating in crises, chronic stress, attention scarcity) and a practice for each.
- **Today**: principle of the day, a daily protocol, a streak, and accuracy by lens.
- **Journal**: everything you save, with copy-to-backup and restore.

All data stays in your browser (localStorage). Nothing is sent anywhere.

## Run it

Open `index.html` in any browser. No build step or server is needed.
To install it as an offline app on a phone, serve the folder over HTTPS (for example with GitHub Pages) and use "Add to Home Screen".

## Edit it

The source is `src/app.html`. After editing, run `./scripts/build.sh` to regenerate `index.html`.
